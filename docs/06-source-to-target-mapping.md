# Source-to-Target Mapping (DWH → Datamart)

Fill the **DWH source** columns with the real DWH table and column names. This is
where your Power BI field analysis is reconciled with the model: every datamart
column should trace back to a DWH column (or a documented derivation), and every
Power BI report field should land in a datamart column.

Legend for **Transform**: `direct` = copy as-is · `lookup` = resolve surrogate
key · `derive` = computed · `scd2` = carry DWH version through.
